# Desktop UX audit — 2 October 2026

## Scope and evidence

This is a review of the current, uncommitted desktop layout. No application or mobile files were changed. Screenshots were taken in Chromium at **1024 × 768**, **1280 × 720**, **1366 × 900**, and **1920 × 1080** using disposable PostgreSQL databases. One fixture had one record in each area; a second had 46 expenses, 25 tasks, and 11 populated categories. The browser run covered Cockpit, Aufgaben, personal and family Finanzen, category detail, Prognose, Setup, Auto, Verträge, Dokumente, Einstellungen, and the global create dialog. All visited routes returned HTTP 200, no browser page errors were reported, and the automated desktop overflow check passed. Category selection and a weekly period link were clicked; the period link opened the correctly scoped entries URL (`category=food`, 12–18 October 2026).

The black **N** circle at the lower left of some screenshots is the Next.js development indicator, not part of the product. Findings marked **code inspection** need a targeted browser reproduction with the named data type before a fix is considered verified.

## High priority

1. **Desktop task and expense sorting is inaccessible.** The only `TaskSortControl` is inside `.task-list-section`, which desktop CSS hides when the task workspace exists. The only `ExpenseSortControl` is inside `.expense-section`, hidden the same way. At all four tested widths the expense entries view had zero visible sort controls. Users with long lists cannot change order from the UI. Keep sorting in the visible desktop list header. [Dense tasks](desktop-ux-audit-2026-10-02/laptop-tasks-dense.png) · [Dense expenses](desktop-ux-audit-2026-10-02/laptop-finance-entries-dense.png). Code: `src/app/(app)/aufgaben/page.tsx`, `src/app/(app)/ausgaben/page.tsx`, `src/app/desktop.css`.

2. **Duplicate expense review is inaccessible on desktop.** `DuplicateReviewPanel` is rendered only in the hidden `.expense-section`; the new desktop workspace does not render it. This removes the UI for identifying and merging duplicate personal expenses. **Code inspection**: reproduce with a known duplicate pair. Code: `src/app/(app)/ausgaben/page.tsx`, `src/app/desktop.css`.

3. **At 1024 px, list and detail stack with a large empty list area, pushing the selected detail below the fold.** The 1024 × 768 task page shows only the selected row and approximately 200 px of empty list card before the detail begins. Finance entries behave the same way. A selected item therefore appears to do nothing until the user scrolls. The one-column breakpoint is below 1180 px, while the list keeps a 360 px minimum height. Either retain an adequately sized split view or let the one-column list fit its content and move the detail close to the selection. [1024 px tasks](desktop-ux-audit-2026-10-02/compact-tasks.png) · [1024 px category detail](desktop-ux-audit-2026-10-02/compact-category-detail.png). Code: `src/app/desktop.css`.

4. **Monthly range captions show the next calendar day.** The October view says `01.10.2026 bis 01.11.2026` on the booking list, while the category detail correctly says `01.10.2026–31.10.2026`. `getExpenseRange` uses the last millisecond of 31 October in UTC; `formatDate` formats that instant in the local time zone, where it becomes 1 November. This makes the selected period and list count appear inconsistent. Format calendar bounds in UTC or format the intended date key. [Expense entries](desktop-ux-audit-2026-10-02/laptop-finance-entries-dense.png) · [Category detail](desktop-ux-audit-2026-10-02/laptop-category-detail-dense.png). Code: `src/lib/expense-range.ts`, `src/lib/format.ts`.

5. **Linked NAS documents in contract details can lead to an empty link.** Both the desktop and original contract detail render every linked document as `<a href={document.url}>`, but a `LOCAL_FILE` reference has no external URL. A family member selecting a linked NAS document from a contract cannot preview or download it there. Use the authorized `/api/documents/file?id=...` route for local references. **Code inspection**: the fixture contained only an HTTPS link. [Contract detail](desktop-ux-audit-2026-10-02/laptop-contracts.png). Code: `src/app/(app)/vertraege/page.tsx`.

## Medium priority

6. **Category detail becomes too narrow at laptop and compact widths.** The desktop page divides the content into a category list and detail, then the detail divides again into chart and weekly list. At 1024 px, the chart is tiny, the week dates wrap over three lines, and the action hint wraps; at 1280 px it is still cramped. Switch the inner chart/period layout to one column before the outer split becomes narrow. [1024 px detail](desktop-ux-audit-2026-10-02/compact-category-detail.png) · [1280 px dense detail](desktop-ux-audit-2026-10-02/laptop-category-detail-dense.png) · [wide reference](desktop-ux-audit-2026-10-02/wide-category-detail-dense.png). Code: `src/app/(app)/ausgaben/analyse/analysis.css`, `src/app/desktop.css`.

7. **Category selection leaves the main finance workspace.** Clicking a category navigates from `/ausgaben?view=categories` to a separate detail route. The finance title, overview/analysis tabs, period navigator, search, filters, and active filter chips disappear; only an icon back button remains. The left category list remains visible, but changing period or filters requires leaving the detail. This conflicts with the intended desktop list-and-detail workflow. [Analysis](desktop-ux-audit-2026-10-02/laptop-finance-analysis-dense.png) · [Detail](desktop-ux-audit-2026-10-02/laptop-category-detail-dense.png). Code: `src/components/finance-detail-analysis.tsx`, `src/app/(app)/ausgaben/page.tsx`.

8. **A populated category analysis still opens with an empty right pane.** Even with 11 categories, the entire right side says “Kategorie auswählen” until the user clicks one. Showing the first visible category by default would make the overview immediately useful and match the automatic selection used by tasks, contracts, documents, and bookings. [Dense analysis](desktop-ux-audit-2026-10-02/wide-finance-analysis-dense.png). Code: `src/app/(app)/ausgaben/page.tsx`.

9. **The floating create button changes shape across desktop heights and overlaps data.** At 1280 × 720 it is a 56 × 56 circle; at 1024 × 768, 1366 × 900, and 1920 × 1080 it becomes a 122 × 48 rectangle showing only `+`, with blank space where the `Neu` label should be. It covers category amounts, the last weekly row, or the edge of detail cards. The mismatch comes from two desktop media conditions, one of which also requires `min-height: 761px`. Align the breakpoints and reserve a content-safe corner. [Finance overview](desktop-ux-audit-2026-10-02/laptop-finance-overview-dense.png) · [1024 px detail](desktop-ux-audit-2026-10-02/compact-category-detail.png) · [wide detail](desktop-ux-audit-2026-10-02/wide-category-detail-dense.png). Code: `src/app/globals.css`, `src/app/desktop.css`.

10. **Category amounts can be misleading with income or mixed currencies.** The selected-category side list renders only `row.spending`, even when the analysis row also shows income. An income-only category would appear as `0,00 €` there. The personal category aggregation also runs without a currency filter when `params.currency` is absent, then formats the combined cents as EUR; the detail page separates currencies. **Code inspection**: reproduce with an income and a non-EUR expense. Code: `src/components/desktop-finance-analysis-list.tsx`, `src/app/(app)/ausgaben/page.tsx`, `src/lib/expense-filters.ts`.

11. **The document tab filter does not govern NAS files in the desktop list.** `desktopRecords` always appends current explorer files after tab-filtered saved references. Choosing **Links** or **verknüpft** can therefore still show raw NAS files in the main desktop list and select one as its detail. Apply the active tab to the combined records or separate the explorer clearly. **Code inspection**: reproduce with a configured document root. Code: `src/app/(app)/dokumente/page.tsx`.

12. **Desktop details omit information available in the existing detail sheets.** The contract inspector shows the automatic debit day but omits its configured expense category and label and the updated date. A saved NAS document inspector omits its relative file path, so the user cannot identify which NAS file a reference points to without opening it. **Code inspection** for these non-fixture states. [Contract detail](desktop-ux-audit-2026-10-02/laptop-contracts.png) · [Document detail](desktop-ux-audit-2026-10-02/laptop-documents.png). Code: `src/app/(app)/vertraege/page.tsx`, `src/app/(app)/dokumente/page.tsx`.

13. **Unbudgeted categories show a full progress bar.** In the dense finance overview, every category labeled “Ohne Budget” has a full-width mint bar, which visually implies 100% usage despite no budget denominator. Hide the bar or use a neutral amount-only treatment when no budget exists. [Dense overview](desktop-ux-audit-2026-10-02/laptop-finance-overview-dense.png). Code: `src/app/(app)/ausgaben/page.tsx` and the budget list styling.

14. **The finance filter dialog has a cramped disclosure label at 1024 px.** `Weitere Filter` runs into `Zahlungsart und Quelle`, and the chevron drops to the next line. This looks like two controls with no clear boundary. [1024 px filter](desktop-ux-audit-2026-10-02/compact-finance-filter.png). Code: `src/components/expense-filter-form.tsx`, `src/app/globals.css`.

15. **Dense desktop lists conceal their independent scrolling.** With 25 tasks or 46 bookings, only a subset of rows is visible in the card and no persistent scrollbar or bottom cue indicates more items. The count and visible rows disagree at a glance. Make the list's scrolling affordance clear, especially when a nested page scroll is also present. [Dense tasks](desktop-ux-audit-2026-10-02/laptop-tasks-dense.png) · [Dense bookings](desktop-ux-audit-2026-10-02/laptop-finance-entries-dense.png). Code: `src/app/desktop.css`.

## Lower priority polish

16. **The booking inspector repeats the same record.** The right pane shows its amount, date, category, label, and store, then embeds the same booking as a second card solely to expose the existing row actions. This spends vertical space and makes the edit path hard to discover. Put edit/document actions in the inspector header and present the record once. [Expense detail](desktop-ux-audit-2026-10-02/laptop-finance-entries-dense.png). Code: `src/app/(app)/ausgaben/page.tsx`.

17. **The empty forecast still draws a zero-valued trend line and scale.** The page says there are no completed months, but the chart shows 12 plotted zero points, which reads as measured history. Use one clear empty state until enough data exists. [Forecast](desktop-ux-audit-2026-10-02/laptop-forecast.png).

18. **Several desktop actions retain touch-oriented copy or underspecified icons.** Category detail says `Tippen für Buchungen`; a mouse and keyboard context calls for `Öffnen` or `Buchungen ansehen`. The two category-row icons are both visually small and similar, although their 44 px hit targets and accessible labels are present. The detail page back and booking-list controls have no visible text. [Analysis](desktop-ux-audit-2026-10-02/laptop-finance-analysis-dense.png) · [Detail](desktop-ux-audit-2026-10-02/laptop-category-detail-dense.png).

19. **Settings do not use wide desktop space well.** At 1920 px, the settings navigation and cards occupy a narrow central region with a large blank area to the right. A wider detail column or a stronger two-column grouping would improve scanning without increasing the text line length. [Wide settings](desktop-ux-audit-2026-10-02/wide-settings.png).

## Verification limits

- The browser fixtures did not include a configured NAS root, a local-file contract reference, duplicate expense groups, multiple currencies, or income-only categories. Those findings are explicitly marked **code inspection** above.
- The screenshots cover desktop viewports only. No mobile screenshots or mobile implementation files were edited for this audit.
- No destructive application action was submitted during interaction checks; all test data lived in disposable databases removed by the screenshot scripts.
